# 🎮 Lumix Studio — Padrão Oficial de Topics (Tags)

Olá 👋  !

Bem-vindo à documentação oficial de padronização de Topics da Lumix Studio.

A organização dos repositórios é essencial para mantermos clareza, profissionalismo e escalabilidade dentro do estúdio.

Todos os desenvolvedores devem seguir este padrão para que seus repositórios sejam aprovados pela moderação.

---

## 📌 Regras Gerais

- Cada repositório deve conter NO MAXIMO 6 TOPCS.
- Todos os topics devem ser escritos:
  - Em letras minúsculas
  - Sem espaços
  - Utilizando hífen (-) quando necessário
- Caso seja necessário adicionar um novo padrão de topic, consulte previamente os Owners ou Administradores.

---

## 🎮 Requisitos Obrigatórios para Repositórios de Jogos

Todos os repositórios de jogos devem conter obrigatoriamente os seguintes topics:

### 1️⃣ Plataforma
Indica onde o jogo será publicado:
- `pc`
- `mobile`
- `web`

---

### 2️⃣ Engine
Indica a engine utilizada no desenvolvimento:
- `construct3`
(Outras engines podem ser adicionadas conforme necessário)

---

### 3️⃣ Status do Projeto
Define o estágio atual do desenvolvimento:
- `prototype`
- `in-development`
- `released`

---

### 4️⃣ Gênero do Jogo
Define o tipo do jogo:
- `action`
- `horror`
- `platformer`
- `puzzle`
- `rpg`
(Outros gêneros podem ser adicionados conforme necessidade)

---

## 📌 Exemplo de Aplicação Correta

Um jogo de terror para web em desenvolvimento feito no Construct deve conter:

horror web construct3 in-development
