# 🎮 Lumix Studio — Padrão Oficial de Repositórios

Olá 👋  

Este documento define o padrão oficial de nomes de repositórios da Lumix Studio.

A padronização é essencial para:

- Evitar desorganização
- Facilitar manutenção
- Ajudar novos desenvolvedores
- Reduzir retrabalho
- Garantir escalabilidade

Todos os projetos devem seguir este padrão obrigatoriamente.

---

# 📌 1️⃣ PADRÃO DE NOMES DE REPOSITÓRIOS

## 🎮 Repositórios de Jogos

Formato obrigatório:

lumix-nome-do-jogo

### ✅ Regras:

- Tudo em letras minúsculas
- Sem espaços
- Utilizar hífen (-)
- Não utilizar underline (_)
- Não utilizar letras maiúsculas

---

### ✅ Exemplos corretos:

lumix-shadow-fear  
lumix-project-echo  
lumix-dark-ritual  

---

### ❌ Exemplos incorretos:

ShadowFear  
lumixShadowFear  
lumix_shadow_fear  
ProjetoLumix  

---

A organização é responsabilidade de todos.
