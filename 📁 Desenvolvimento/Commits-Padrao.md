## Padrões de commit do Estúdio
Para fins de organização, a Lumix tem um padrão de  mensagem específico para os **commits**.
<br>
Logo abaixo está os tipos:

| Tipo | Função |
| ---- | ------ |
| feat | adiciona novas funcionalidades |
| update | atualização e códigos |
| fix | correção de bugs |
| refactor | refatoração de código |
| org | organização de arquivos |

<br>

# Como enviar sua mensagem de commit
### No Site/Github Desktop
```
tipo: mensagem
```

### No Git
```
git commit -m "type: mensagem"
```
